# Data Templates
Collection of reusable data templates (.csv) for OECT data.
Designed to provide a consistent data structure for working with Python analysis scripts.
Main idea: to transform raw data obtained from measurements into organized ones for the Python-driven plotting.

## OECT-tf.csv
Copy and paste gate voltage values, $V_g$ and corresponding drain current values, $I_d$.
## OECT-output.csv
Step 1. Copy and paste drain voltage values, $V_d$ and corresponding sets of $I_d$ under their fixed $V_g$ values.
Step 2. Revise each $V_g$ value in the header row for correct labelling.
## OECT-transient.csv
Copy and paste time, $t$ and $I_d$.
