# OECT-Data-Analysis
Simple Python scripts for analyzing organic electrochemical transistor (OECT) characteristics.

My motivation:
As a complete beginner to Python and GitHub, I created this repository to organize the small tools I use throughout my research workflow. 

## Current Features

- Transfer curve ($I_D$-$V_g$) plotting
- Output curve ($I_D$-$V_D$ at multiple fixed $V_g$ values) plotting
- Transient response ($I_D$-$t$) analysis
  - With curve fitting for response time $\tau$

## Requirements

- Python 3.x
- pandas
- numpy
- matplotlib
- scipy
